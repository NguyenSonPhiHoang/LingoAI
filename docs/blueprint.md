# **App Name**: LingoAI

## Core Features:

- Personalized Lesson Recommendations: AI-powered learning path generator to suggest personalized lessons based on the user's current level and learning goals. The LLM will act as a tool to generate the optimal path.
- Level-Based Content Display: Display of learning content organized by level (beginner, intermediate, advanced).
- Four Skills Exercises: Interactive exercises for each level, including listening comprehension, speaking practice (voice recording), reading comprehension, and writing prompts.
- Personalized Vocabulary Lists: Personalized vocabulary lists where users can add and review new words encountered during lessons.
- User Account Management: User account creation and management for tracking progress and personalizing learning paths.
- User Progress Tracking: Progress tracking to display progress and encourage active learning.

## Style Guidelines:

- Primary color: HSL 49, 100%, 50% (approximately #FFB300 in hex). The bright yellow creates a feeling of optimism.
- Background color: HSL 49, 20%, 95% (approximately #F5F2EC in hex). A very light tint of yellow serves as a clean background.
- Accent color: HSL 19, 90%, 50% (approximately #FA5100 in hex). A warm orange/red offers good contrast and draws attention to key actions.
- Body and headline font: 'Inter' sans-serif for a modern, clean, readable interface.
- Use clear, simple icons to represent different learning activities (listening, speaking, reading, writing).
- A clean and intuitive layout is key, ensuring easy navigation between levels and activities.
- Use subtle animations to provide feedback on user interactions (e.g., correct/incorrect answers, progress updates).
